# Portfolio | Evaluación de proveedores

Caso práctico de IA aplicada a una decisión de compras. A partir de un conjunto ficticio de pedidos, contratos y ofertas, preparé un análisis de servicio y calidad, una recomendación de renovación y una presentación para comité.

**Alcance:** 600 pedidos emitidos entre julio y septiembre de 2026. Las tasas de servicio se calculan sobre 521 pedidos emitidos y recibidos dentro del trimestre.

**Resultado del ejercicio:** propuesta provisional de renegociar con cuatro proveedores y estudiar una alternativa para ElectraSupply. Cualquier firma, sustitución o traslado de volumen requiere revisión humana.

## Límites

El caso utiliza una empresa, firma y datos ficticios. El índice de precio de las ofertas es relativo a 100: no permite calcular un ahorro en euros. Los descuentos propuestos no son acuerdos firmados. La capacidad de proveedores alternativos y algunos criterios de calidad quedan pendientes de validación.
